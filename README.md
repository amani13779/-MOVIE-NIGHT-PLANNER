# -MOVIE-NIGHT-PLANNER


Movie Night Planner is a web application that helps users organize and manage their personal movie watchlist. Users can add movies, choose a genre, rate them, write notes, and update their watch status. The application is built using PHP and MySQL, with a responsive interface created using HTML, CSS, and JavaScript.

## Live Demo

https://amani13779.github.io/-MOVIE-NIGHT-PLANNER/

## Features

- Add a new movie.
- Choose a movie genre.
- Rate movies from 1 to 5 stars.
- Add personal notes.
- Change the watch status using the Toggle button.
- Update the status instantly without refreshing the page.
- Store and retrieve data from a MySQL database.

## Project Overview

The application allows users to enter movie information through a form. The submitted data is stored in a MySQL database and displayed in a table on the same page. Each movie includes a Toggle button that changes its watch status without reloading the page. The project was hosted on InfinityFree and the interface is available through GitHub Pages.
